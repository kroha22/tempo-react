# Озвучка карточек

`CardSpeechButton` подключён к колодам глаголов, базовых слов и школьных инструкций, а также к тематическим карточкам. Он читает португальскую сторону независимо от переворота. В школьной колоде пример читается отдельно.

В раскрывающихся настройках выбираются язык и установленный голос. По умолчанию: `pt-PT`, с приоритетом Joana. Выбор общий для карточек и сохраняется на устройстве. Пропавший голос не подменяется автоматически. «Проверить голос» произносит фразу `Olá! Estou a falar português de Portugal.` выбранным голосом.

При каждом нажатии голос заново разрешается из `speechSynthesis.getVoices()`, в utterance явно задаются `voice` и `lang`. Для Safari/WebKit язык дополнительно указан в SSML `<lang xml:lang>`; другие движки получают обычный текст. Поддержка SSML описана в [докладе Apple](https://developer.apple.com/videos/play/wwdc2022/10153/). Настройки в интерфейсе показывают запрошенный голос: Web Speech API не предоставляет подтверждение фактически использованного системного голоса.

Повторное нажатие, переход на другую карточку, смена языка/голоса или уход с экрана останавливают предыдущее воспроизведение. Озвучка не меняет ID, очереди, оценки и хранение прогресса. Аудиофайлы и серверный синтез не используются.
