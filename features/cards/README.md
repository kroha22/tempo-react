# Озвучка карточек

Для сравнения произношения в выборе языка оставлены четыре локали: `pt-PT`, `pt-BR`, `es-ES`, `fr-FR`. Сохранённый выбор другого языка отображается как начальный `pt-PT` / Joana. Голоса внутри каждой доступной локали выбираются из каталога устройства; при отсутствии голосов кнопка озвучки недоступна.

`CardSpeechButton` подключён к колодам глаголов, базовых слов и школьных инструкций, а также к тематическим карточкам. Он читает португальскую сторону независимо от переворота. В школьной колоде пример читается отдельно.

В раскрывающихся настройках выбираются язык и установленный голос. По умолчанию: `pt-PT`, с приоритетом Joana. Выбор общий для карточек и сохраняется на устройстве. Пропавший голос не подменяется автоматически. «Проверить голос» читает текст текущей карточки выбранным голосом, одинаково для всех языков.

Португальский Португалии (`pt-PT`) и Бразилии (`pt-BR`) — отдельные локали, как французский Франции (`fr-FR`) и Канады (`fr-CA`). Список голосов фильтруется по точной локали для всех языков одинаково. Единственное исключение — начальный выбор `pt-PT` и приоритет Joana при отсутствии явного выбора голоса. Старые настройки группы `pt` преобразуются в локаль сохранённого голоса, не сбрасывая его. Язык utterance всегда соответствует выбранному голосу.

При каждом нажатии голос заново разрешается из `speechSynthesis.getVoices()`, в utterance явно задаются `voice` и `lang`. Все движки получают обычный текст без SSML: строка user agent не доказывает поддержку разметки во встроенном браузере. Настройки в интерфейсе показывают запрошенный голос: Web Speech API не предоставляет подтверждение фактически использованного системного голоса.

Повторное нажатие, переход на другую карточку, смена языка/голоса или уход с экрана останавливают предыдущее воспроизведение. Озвучка не меняет ID, очереди, оценки и хранение прогресса. Аудиофайлы и серверный синтез не используются.

Остановка вызывается только для активного воспроизведения карточки. Завершённая фраза не сбрасывает движок перед следующим нажатием. Все контролы используют один активный utterance; уход с прежней карточки не может остановить уже запущенную новую. Повторные вызовы с тем же голосом и языком проверяются тестами. Это проверка переданных настроек, а не автоматическая оценка языка реально прозвучавшего аудио.

Каталог загружается через `voiceschanged` и ограниченные повторные чтения (до 3 секунд), если браузер не прислал событие. До окончания загрузки показано состояние ожидания. Каждый вызов создаёт новый utterance, удерживает его до завершения и передаёт канонический BCP 47-код выбранного голоса. Скорость, высота и громкость явно равны 1; при приостановленном движке перед стартом вызывается `resume`. Голос другого языка не подставляется.
