# Озвучка карточек

Базовая колода содержит 357 слов: исходные 351 запись сохраняют порядок и ID, шесть отсутствовавших школьных глаголов добавлены в конец без дублей. «Инструкции на уроке» находится во вкладке «Фразы» и показывает целые инструкции с переводом; инфинитив остаётся подсказкой и связью с исходным глаголом.

`CardSpeechButton` читает португальскую сторону карточки или фразу. Начальный голос — Joana, `pt-PT`. Скорость, высота и громкость равны 1; каждый вызов заново получает голос из каталога устройства и передаёт обычный текст без SSML.

Общая иконка «динамик + !» расположена над правым верхним углом карточки либо в заголовке группы фраз. Она открывает короткое окно помощи: пользователь может включить запасной Grandpa (`pt-BR`) или вернуться к Joana. Выбор общий для всех динамиков и сохраняется на устройстве. При отсутствии нужного голоса настройка не меняется; окно объясняет причину. Список голосов и открытие настроек удержанием динамика убраны.

Системная подмена голоса на Samantha не видна через Web Speech API: события start/end могут завершиться успешно. Запасной голос включается пользователем, автоматического распознавания такой подмены нет.

В «Слова → Фразы» читаются примеры и правильное предложение после проверки; до проверки озвучка ответа отсутствует. Смена скрываемого режима отключает его воспроизведение. В школьной колоде пример читается отдельно.

Каталог загружается через voiceschanged и ограниченные повторные чтения до 3 секунд. Новый utterance удерживается до завершения. Остановка применяется только к активному воспроизведению: завершённая фраза не сбрасывает движок. Смена карточки или голоса прекращает прежнюю озвучку. Аудиофайлы и серверный синтез не используются. ID карточек, оценки, очередь и хранение прогресса не меняются.
