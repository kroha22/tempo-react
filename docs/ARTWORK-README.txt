возможного использования внутри уроков и как образцы персонажей.

Этот пакет фиксирует художественные материалы и самостоятельный реестр.

Обложки проверены в текущем рабочем приложении; один художественный коммит
сам по себе не означает публикацию или перенос всех рабочих изменений UI.
