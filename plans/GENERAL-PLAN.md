# Общий план обучения

## Взрослый профиль · единый маршрут · 2026-11-18

Взрослый профиль Pages использует `AdultGeneralPlan`: одно продолжение, десять раскрывающихся коммуникативных блоков и общий вход «Слова и повторение». Обязательные занятия берутся из `adult-route-lessons.ts`, остальные материалы — из того же реестра `adult-route.ts`; будущие темы находятся внутри своих блоков, без отдельного курса книги или школы. Взрослый каталог поиска использует те же десять блоков и ссылки.

Обновление 2026-11-19: `adult-catalog.ts` строит поисковую проекцию реестра. `AdultLearningCatalog` не вычисляет прогресс и не задаёт обязательный порядок. Одинаковые назначения URL объединяются только в выдаче, с сохранением всех reference keys и поисковых названий. Старые тематические кнопки остаются в блоках, семь прежних контейнеров упражнений имеют compatibility placements в том же реестре. Общие словари/спряжение доступны как инструменты; старые скрытые из витрины подборки доступны по точному ID и при соответствующем поиске. Поиск и раскрытые блоки — только UI-состояние; вход «Все темы» взрослого профиля больше не возобновляет автоматически lastTopicId. Продолжение остаётся в общем плане. Детский и unprofiled legacy каталоги не заменены.

Возврат из взрослого урока, открытого в каталоге, использует «К каталогу тем» и сохраняет поисковую выдачу. Обычный вход из плана и явная глобальная ссылка «Общий план» сохраняют прежнее назначение. Контекст возврата не записывается в профиль и не меняет адреса или результаты самих уроков.

Результаты читаются через `readAdultProgress` из трёх существующих владельцев одного профиля. Ошибка чтения не показывается как нулевой прогресс. Прежнее подтверждённое прохождение сохраняет отметку при активном повторении. 49 базовых занятий не означают освоение всего блока; контентные пробелы явно доступны внутри него.

На Pages короткие Route-вопросы сохраняются как ActivityResult и отмечаются как короткая практика; они не выдаются за server-assessed checkpoint. Форматы, IDs, Card Save/SRS и JSON не меняются. Детский и unprofiled legacy план сохраняют прежнюю компоновку.

Ссылка `/learning/quick-words?set={encodedSetId}` открывает исходную подборку, `&resume=1` восстанавливает её сохранённые stage/index/mode текущего профиля без записи при открытии. Прежние topic/source ссылки работают. Возврат из занятия в Pages раскрывает исходный блок и фокусирует его заголовок; это временный UI-контекст, без нового ключа сохранений.

«Еда и предпочтения» собрана в [полный флоу F-08.2](FOOD-FLOW-F08-2.md): объяснение PT/RU, готовые слова и SRS из F-08.1, прежние задания с раздельными результатами 6/8/5/2. [Карта F-07](FOOD-FLOW-F07.md) сохраняет исходные решения.

## Прежняя компоновка · детский и legacy входы

План содержит все 54 темы Gramática Ativa 1: U01–U30 имеют объяснения и проверки, U31–U54 — доступные словарные пачки и явную отметку о подготовке заданий. К темам привязаны прежние короткие грамматические уроки. Остальные девять словарных и бытовых занятий доступны отдельным блоком с прежними ID через `/learning/plan/step/:id`.

Проверка по книге и короткая практика имеют самостоятельные результаты: прохождение короткого урока не засчитывает проверку книги. План читает существующие хранилища, не переносит и не обнуляет результаты. Счётчик проверок учитывает ранее подтверждённое освоение даже при начатом повторном прохождении.

Продолжение выбирает последнюю активную проверку по сохранённому `updatedAt`. Это существующее поле локального документа теперь сохраняется при чтении DTO; оно необязательно для старых ответов API. При отсутствии активной проверки предлагается первая новая тема. Возврат из проверки, объяснения, словарной пачки и повторения ведёт к общему плану. Повторный вход в план обновляет результаты.

Глобальная навигация: «Общий план», «Все темы», «Карточки». Каталог тем и колоды остаются смонтированными при переходах, чтобы сохранять выбранную тему и текущие ответы. Старый список из 23 занятий служит моделью прежнего прогресса и исполнителем дополнительных занятий, а не вторым публичным планом.

Публичное сохранение остаётся локальным, по профилям, с прежним экспортом и импортом JSON. ID уроков, карточек, SRS, форматы сохранения и алгоритм повторений не меняются. При ошибке загрузки план предлагает повторить чтение и не показывает неизвестный прогресс как нулевой.
