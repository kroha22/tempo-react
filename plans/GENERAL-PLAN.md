# Общий план обучения

Основной вход публичного приложения — `/learning/plan` (также корневой адрес профиля). Прежний `/learning/gramatica-ativa` открывает тот же экран. Книги остаются отдельным приватным продуктом.

План содержит все 54 темы Gramática Ativa 1: U01–U30 имеют объяснения и проверки, U31–U54 — доступные словарные пачки и явную отметку о подготовке заданий. К темам привязаны прежние короткие грамматические уроки. Остальные девять словарных и бытовых занятий доступны отдельным блоком с прежними ID через `/learning/plan/step/:id`.

Проверка по книге и короткая практика имеют самостоятельные результаты: прохождение короткого урока не засчитывает проверку книги. План читает существующие хранилища, не переносит и не обнуляет результаты. Счётчик проверок учитывает ранее подтверждённое освоение даже при начатом повторном прохождении.

Продолжение выбирает последнюю активную проверку по сохранённому `updatedAt`. Это существующее поле локального документа теперь сохраняется при чтении DTO; оно необязательно для старых ответов API. При отсутствии активной проверки предлагается первая новая тема. Возврат из проверки, объяснения, словарной пачки и повторения ведёт к общему плану. Повторный вход в план обновляет результаты.

Глобальная навигация: «Общий план», «Все темы», «Карточки». Каталог тем и колоды остаются смонтированными при переходах, чтобы сохранять выбранную тему и текущие ответы. Старый список из 23 занятий служит моделью прежнего прогресса и исполнителем дополнительных занятий, а не вторым публичным планом.

Публичное сохранение остаётся локальным, по профилям, с прежним экспортом и импортом JSON. ID уроков, карточек, SRS, форматы сохранения и алгоритм повторений не меняются. При ошибке загрузки план предлагает повторить чтение и не показывает неизвестный прогресс как нулевой.
