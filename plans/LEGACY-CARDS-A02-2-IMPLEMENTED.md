# A02.2 · Доступ к 17 целям и подключение повторения

2026-11-14. База: `512e1b43a004b49d334dd7bee6908ec2d60f5e40`. Продолжение [A02.1](LEGACY-SRS-A02-1-IMPLEMENTED.md) по [карте A02–A05](LEGACY-SRS-A02-A05.md). Взрослый интерфейс; детский курс не расширяется.

## Пользовательский путь

Общий план, раздел карточек и библиотека сохранений → «Слова прежних уроков». Прямой Pages-вход: `#/learning/legacy-cards?group=intro`. Четыре группы: знакомство — 5; кто и как себя чувствует — 2; что у кого есть — 4; где расположено место — 6. Каждая содержит PT/RU, прежние примеры, озвучивание, действие сохранения и ссылку на исходное объяснение. В четырёх коротких Route-уроках добавлен обратный вход к соответствующей группе.

Три дополнительные фразы знакомства взяты из уже существующего словаря. Старые saveItemIds урока (2), задания и completion criteria не расширены.

Для новой цели показано «В карточки»; для сохранённой без review — «Подключить повторение»; при наличии любого review — «Повторение подключено ✓». В библиотеке действие доступно рядом с каждой из этих 17 целей. Общая очередь группы фильтрует прежний StudyReview по точным 17 IDs и использует тот же scheduler и сохранения, что основная очередь.

## Совместимость и ошибки

- Чтение/импорт ничего не активируют. Явный Save использует существующий API и создаёт только отсутствующий review. Неизвестное, загружающееся или ошибочное состояние не считается отсутствием.
- Сохранённый источник переиспользуется целиком, включая sourceType/sourceContextId. Имеющиеся savedAt, остальные источники и reviews не сбрасываются; порядок библиотеки сохраняется. У сохранения без источника библиотека предлагает выбрать реальный источник на странице слов; выдуманных источников нет.
- Ответ Save не выдаётся за подтверждённое расписание: выполняется чтение reviews. Ошибка этого чтения предлагает только повторить проверку. При потере ответа Save повторяется тот же intent/clientEventId. После смены профиля старый ответ не заполняет новый cache.
- Сигнатура клиентского saveStudyItem расширена до существующего SaveStudyItemInput для сохранения всех поддерживаемых типов источника. Wire contract, API handlers, schema, scheduler, backup format не менялись.
- Статический снимок A02.1 и текущие pack/catalog/review definitions/source metadata/verbCards полностью совпали: 665 StudyItems, 665 definitions, 72 metadata, 1000 глаголов. Новых canonical IDs нет.

Проверка 401/403 библиотеки учитывает дополнительное чтение review-status, сохраняя проверку отсутствия retry loop.
