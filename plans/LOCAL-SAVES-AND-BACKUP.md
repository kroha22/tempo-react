# Локальные сохранения и JSON-копии

Решение пользователя от 2026-11-03: публичный Tempo на GitHub Pages работает без серверного API и без подключения Cloudflare. Это явно заменяет прежнее требование D1 как источника прогресса для опубликованной статической версии. Локальная серверная версия и её таблицы остаются без изменений; удалять или переносить данные D1 эта работа не должна.

## Источники данных

- Существующие профили, колода 1000 глаголов, план, темы и награды сохраняют прежние localStorage-ключи и форматы. Не выполняется автоматическое копирование старых безымянных результатов в профиль.
- IndexedDB `tempo-learning`, store `profiles`, ключ существующего профиля: сохранённые StudyItems, все источники, SRS, квитанции оценок, ответы и границы уроков Gramática Ativa.
- `LocalLearningBoundary` открывает и проверяет хранилище до запуска занятий. Ошибка открытия или проверки не подменяется пустым прогрессом. Кэш Query по-прежнему ограничен профилем.
- Локальный адаптер подключается только из GitHub Pages. Существующие UI-хуки используют прежние DTO, чистый `scheduleStudyReview`, проверки ответов и стабильные `saved:<studyItemId>` IDs. Действие подтверждается после завершения IDB-транзакции. Между вкладками оценки защищены read/write-транзакцией, версией и идентификатором команды.
- Ответ «Знаю» и пропуск в пачке слов остаются решениями текущего просмотра; они не означают освоение и не меняют SRS. Сохранённые карточки сохраняются постоянно.

## Копия и восстановление

«Сохранения и резервная копия» находится над занятиями. Один JSON содержит выбранный профиль: прежние данные localStorage и новые данные IndexedDB. Остальные профили, глобальные настройки озвучки и прежние безымянные ключи не изменяются и в этот файл не входят. Для каждого профиля нужна своя копия.

Формат `tempo-profile`, версия 1, дата выгрузки, метаданные профиля и два набора данных. Предел файла 10 МБ. Схемы и ссылки проверяются до записи; неизвестные версии отклоняются. Имена и содержимое отображаются обычным React-текстом. Файл не содержит токенов или серверной идентичности.

Перед восстановлением показаны исходное имя, дата, объём и целевой профиль. Копия объединяется с выбранным профилем, не меняя его ID, имя или оформление. Для переноса на другое устройство сначала создайте там профиль, затем импортируйте копию.

Правила объединения:

- StudyItems и все привязки к урокам объединяются без дублей; IDs не меняются.
- SRS Gramática Ativa выбирается по `reviewedAt`; равная дата сохраняет текущую запись. При замене существующей записи версия повышается, чтобы отвергать устаревшие команды открытой вкладки.
- У старой колоды нет времени изменения, поэтому при совпадении ID сохраняется текущий интервал. Отсутствующие карточки добавляются.
- Завершение и demonstrated не отменяются. Курсор определяется временем изменения; повторная попытка не стирает прежнее достижение.
- План объединяется существующим доменным merge; просмотренные слова и награды сохраняются. При совпадении результата активности выбирается лучший процент правильных ответов.
- Двухфазная запись защищена журналом `tempo-react:pending-import:<profileId>:v1`. Сначала сохраняется проверенный файл, затем объединяются IDB и localStorage; журнал удаляется последним. Незавершённый импорт повторяется при следующем открытии профиля. Квота и ошибка записи показываются пользователю.

Это локальное хранение, не синхронизация устройств. Браузер может удалить данные при очистке/в приватном режиме; запрос persistent storage является дополнительной защитой, а не гарантией. Копию следует сохранять после занятий. Импорт не удаляет профиль или сохранения. Старые серверные данные не скачиваются автоматически: сервер в этом варианте не подключён.

## Проверка

Автоматические сценарии: повторный save и источники, идемпотентность оценки и конфликт версии, resume и выходные ответы, round trip, старая копия поверх нового SRS, изоляция профилей, отказ повреждённому файлу, восстановление после сбоя двух хранилищ, сохранение завершения. Реальный IndexedDB и мобильный поток проверяются в браузере отдельно.
