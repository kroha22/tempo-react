# Карточки из объяснений

В подсказке слова португальских грамматических объяснений появилась кнопка «В карточки». Сохранение использует общий /api/study-items и текущий локальный транспорт профиля; Cloudflare и новая база не требуются. Исходные Lesson/StudyItem IDs и формат резервной копии не меняются.

Существующие словарные значения используют прежний StudyItem. Несколько значений показываются отдельно для осознанного выбора. Для грамматического presente явно исключён перевод «подарок», для ouvir в описании звучания выбрано значение «слышать». Остальные совпадения опубликованных терминов и словаря проверены по смыслу.

Недостающие термины сохраняются как заранее заданные фрагменты чтения (Chunk), а не как автоматически угаданные существительные или новые глагольные леммы. Группа форм имеет один стабильный ID study:reading:<ключ>; ключи опубликованных групп нельзя переименовывать при редактуре перевода. Русский текст и группировка взяты из существующего глоссария. Это необязательные карточки узнавания, они не добавлены к оцениваемым целям или обязательной нагрузке урока.

Источник содержит ID объяснения и, для GA1, unit:ga1:uNN. В библиотеке есть обратная ссылка. Экран /learning/gramatica-ativa/saved («Мои карточки из уроков») доступен из основных колод; из него можно перейти к SRS. Повторное добавление сохраняет старый SavedStudyItem и SRS; добавляется только недостающий source. Перечень встречаемости в объяснениях дополняет прежние словарные связи с юнитами. Новые фрагменты входят в общую очередь SRS, в фильтры соответствующих уроков и в существующий JSON-экспорт/импорт.

Кнопка блокируется во время записи. Успех показывается после подтверждения хранилища. Повтор после ошибки отправляет тот же intent/clientEventId. Query cache обновляется в пределах активного профиля; расписание и ответы урока не перезаписываются. Если для подсказки не передан учебный источник, сохранение не предлагается.

Проверки: реальное локальное API с повторным сохранением ранее оценённой карточки; неизменность SRS и receipts; запись нового термина и его отображение в библиотеке; повторный JSON-импорт без дублей; повтор ошибки с тем же intent; разрешение всех подсвечиваемых слов в канонические карточки. Отдельная проверка браузера и сборки обязательна перед публикацией.
