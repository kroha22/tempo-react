## Доступный результат

- Все темы → Дом → «Дом в личные карточки и повторение»; Пространство и направления → «Расположение в личные карточки и повторение».
- `#/learning/home/cards?topic=rooms|objects|location`, `&mode=review` — очередь сохранённых целей этих трёх пачек по общему SRS.
- Три прежних коротких урока familiar objects / locate-object / possession-and-presence открывают слова через «Слова в личные карточки и повторение». Параметр `source=route` выбирает только заранее заданный source и подмножество исходных saveItemIds этого урока: комнаты 2, предметы 7, расположение 5. Новые четыре комнаты не приписываются уроку TER/HÁ, где их не было. Полные пачки остаются 6/7/5; произвольный source ID из URL не принимается.
- В библиотеке работают ссылки на пачку и на прежнее объяснение. Первой остаётся взрослая стандартная подача; новый детский банк не создавался.

## Цели и источники

[home-cards.ts](../features/content/home-cards.ts) задаёт явные соответствия F-11. **18 целей = 4 новые StudyItems + 14 существующих**. Четыре новые комнаты: cozinha, casa de banho, escritório в смысле домашнего кабинета, garagem. Quarto/sala используют прежние `study:noun:*`, остальные существующие noun/chunk IDs также не менялись.

Из 14 существующих семь уже имели SRS (mesa/chave/livro и четыре отношения), семь получили недостающие review definitions. Существующие семь definitions не перезаписываются: front/back, примеры, книжные units и lowerPriority сохраняются. Нет новых копий house-mesa/house-janela и четырёх позиционных chunks.

Зарегистрированы три источника пачек `lesson:home:rooms|objects|location` и metadata под тремя прежними route source IDs `lesson:a1-1:name-familiar-objects`, `lesson:a1-1:locate-object`, `lesson:a1-1:possession-and-presence`. Старые sourceType/sourceId/sourceContextId не переписываются. Metadata существующих 63 источников сохранены; теперь их 69.

Счётчики: StudyItems 661 → 665, review cards 637 → 648. Адаптеры `study:home:*` исключены из legacy lessonWords, поэтому learningCatalog, банк 51 слова, исходные collections, accepted answers и хеши старых заданий не меняются. Схема image-house остаётся на 24 подписи с прежними координатами/ID; частичный набор не записывается как её полное прохождение.

## Редакторские исправления

Только четыре старых StudyItems меняют `defaultExampleId` и `contentRevision` 1 → 2:

| StudyItem | Новый основной пример | Источник |
|---|---|---|
| `study:noun:quarto` | A cama está no quarto. | Готовый house example |
| `study:noun:caixa` | O gato está dentro da caixa. | Готовый пространственный пример |
| `study:noun:porta` | A porta está aberta. | Короткий новый пример на существующей конструкции |
| `study:chunk:onde-esta` | Onde está o gato? | Готовый вопрос route lesson |

Их ID, target, display, перевод и cardEligible неизменны. Новые Example entities имеют собственные ID `example:home:*` и RU-строки; старые общие примеры не удаляются и не редактируются. Для четырёх новых комнат добавлены четыре примера из house owner. Итого 8 новых Examples, без нового банка упражнений.

Семь готовых review cards не подменены ошибочными manifest defaults. Исправления ESTAR/TER и других дополнительных целей из замечаний F-11 не входят в этот мост. Ревизии Route flows и упражнений остаются прежними, поэтому учебный прогресс не перезапускается.

## Прежняя сохранённая карточка без review

API/storage/scheduler не менялись. Используется прежнее поведение POST Save: если item уже сохранён, сохраняются savedAt и sources; добавляется новый source; review version 0 создаётся только если записи ещё нет. Уже имеющийся отзыв, даже у ранее неподдерживаемой цели, не перезаписывается.

GET и JSON import не выполняют скрытый backfill. До явного Save старый item без review не объявляется автоматически готовым к интервальному повторению. В пачке эта ситуация объясняется перед действием; SaveChoice позволяет добавить новый источник к существующему item. После сохранения повторение доступно и в тематической, и в общей очереди.

## Проверки

Четыре новых domain tests: 4/14/7/7 и точные target IDs; четыре подходящих default examples и прежние flow revisions; неизменные книжные SRS definitions; исходные 51 слово / 24 hotspot / house-a-casa / принятые ответы / source IDs.

Пять component tests: Save всех 18 целей и переключение пачки на прежний route source без повторного монтирования экрана (save intent меняется вместе с источником); JSON старых items без reviews и явное создание ровно семи rows version 0; восемь оценённых целей (включая newly-supported caixa) без сброса reviews/receipts/Route progress; потерянный ответ Save → идемпотентный retry и корректный пример/оба backlinks; scoped SRS и повторный JSON import с сохранением посторонней карточки и отдельного пустого store.

Структурное сравнение с точной F-10.2 подтвердило: все старые entities и RU совпадают, кроме двух разрешённых полей четырёх StudyItems; все 637 старых review cards, 63 источника и learningCatalog совпадают полностью. Новый контент прошёл content validation: 665 StudyItems, 1000 legacy verbs.

Финальные check/build, browser 390×844/desktop и публикация фиксируются по точному SHA в приватном актуальном roadmap. Общий четырёхшаговый урок, новый scene engine, полная checkpoint-оценка и legacy aliases `/learning/house` / `/cards/house` остаются F-12.2; этот этап добавляет работающие новые входы, а не объявляет исправленными все старые адреса.
