# F-04 · Время и мой день

Взрослый пилот единой темы. Основной вход: `/learning/time-day?topic=hours&phase=explanation`; доступен из общего плана и каталога. Разделы: `hours`, `months`, `routine`. В каждом четыре шага: объяснение → слова → задания → повторение, с прямыми ссылками и возвратом.

## Владельцы и границы

Объяснения и задания переиспользуют ClockLesson, TestPreparation (hours/months), CalendarLesson и MyDayOverview/UsagePractice. Нового банка ответов нет. Отдельные материалы календаря и распорядка остаются в раскрываемом разделе каталога; старые адреса и подготовка-совместимость сохранены.

Результаты остаются самостоятельными: `prep:hours`, `clock:read`, `clock:set`, `prep:months`, `prep:months:order`, `prep:months:days`, `usage:calendar:months-first`, `usage:calendar:months-last`, `usage:my-day`. Просмотр объяснения, слова или переход к повторению не создаёт завершение темы.

URL восстанавливает раздел и шаг после reload. Незавершённые ответы сохраняются при переходах между шагами и разделами текущего флоу, включая возврат из связанной грамматики на Pages. После reload восстанавливаются подтверждённые результаты, карточки и расписание; черновики ответов не обещаны. Серверный маршрут собирается, но браузерная приёмка ниже относится к публичному Pages.

## Слова и личная колода

`features/content/time-day.ts` связывает 28 существующих слов: часы 4, месяцы 12, распорядок 12. Исходные word IDs не меняются. Четыре личных StudyItem (acordar, ir, estudar, voltar) повторно используются с прежними ID; остальные 24 получают стабильные адаптеры `study:time-day:*`. Адаптеры — цитаты существующих материалов, без выдуманных морфологических полей. Они исключены из исходного банка упражнений, чтобы не менять старые fallback IDs подготовки.

Значения `tomar` «принимать лекарство» и «принимать решение» не объединены с завтраком. Для завтрака сохраняется исходная фраза «Tomo o pequeno-almoço às sete e meia.» с исходным переводом.

«В карточки» использует существующий идемпотентный Card Save. Источники `lesson:time-day:hours|months|routine` ведут к соответствующему шагу слов. Добавление нового источника существующей карточке сохраняет её отзывы, расписание и остальные источники. Общий SRS фильтрует очередь по 28 target IDs, но сохраняет полный общий query cache; планировщик не менялся. Повторяются только добавленные карточки, когда наступает срок. Пустой фильтр не означает всю колоду.

Хранилища и JSON backup не менялись: Pages сохраняет личные карточки/SRS в существующем IndexedDB, результаты заданий — в профиле браузера. Сервер/API/D1 не подключались. Отдельная колода 1000 глаголов не мигрировала.

## Проверка

- `npm run check`: lint, TypeScript, 122 domain / 313 component / 20 server tests и production build прошли на Node 22.23.2.
- `npm run build:pages`: валидация 619 StudyItems и 1000 глаголов; guard ресурсов 87 ссылок / 114 файлов.
- `tests/time-day.test.ts`: идентичность источников, 28 целей, смысл завтрака и повторное использование старых ID.
- `tests/components/time-day-flow.test.tsx`: ответы часов/месяцев и распорядка после переходов; Card Save к уже оценённой карточке; изолированная очередь и общий SRS; пустой фильтр; возврат из грамматики.
- Browser 390×844: часы → слова → сохранение → оценка; месяцы → слова → оценка; ответы сохраняются при возврате. Распорядок 3/3, переход в грамматику и обратно, результат и сроки после reload. Desktop 1440×1000: сетка слов без горизонтального переполнения. Озвучка использует голоса устройства; качество системного голоса не проверялось.
