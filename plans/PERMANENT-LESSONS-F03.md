# F-03: постоянные уроки вместо пункта подготовки

Оставшиеся десять математических и world-тем подключены к постоянным разделам. Сначала проверены все 20 исходных тем и legacy-возвраты (42 сценария прошли), затем удалена только карточка подготовки в основном каталоге. Старый `school:preparation` сохраняется как совместимый вход; исходные preparationUnits и исполнитель остаются общими, без копирования вопросов и словарей.

## Постоянные входы

В существующих темах календаря, тела и сотрудничества появился блок «Уроки по теме». Для порядковых числительных, здоровья и линии времени добавлены самостоятельные карточки в «Школьные материалы». Это предметные уроки, а не отдельная программа подготовки.

|---|---|---|---|---|
| hours | Часы и сутки | `topic:vocabulary-calendar` | `lesson:preparation:hours` | `prep:hours`, `clock:read`, `clock:set` |
| months | Месяцы и дни | `topic:vocabulary-calendar` | `lesson:preparation:months` | `prep:months`, `prep:months:order`, `prep:months:days` |

## Совместимость и сохранение

- Новые `lesson:preparation:<unitId>` — только навигационные ключи продолжения. Unit IDs, activity IDs, word IDs, карточки, SRS, формат профиля и JSON backup не меняются. Новая версия данных или массовое переписывание профилей не нужны.
- Старый lastTopicId=`school:preparation` открывает прежний набор из 20 тем; он не показывается как карточка каталога. Просмотр не обнуляет старые результаты. Новый выбор сохраняет новый ключ продолжения обычным прежним механизмом профиля.
- TestPreparation получает только постоянный заголовок/возврат к родительской теме. Вопросы, ответы, бумажные поручения и замечания об исходных листах остаются прежними. Схема тела, часы и упражнения месяцев используются встроенно с теми же IDs.
- При переходе к связанному материалу исходный урок остаётся смонтированным и скрытым. «Вернуться к уроку» возвращает к тому же выбранному/проверенному ответу. Проверяется и второй переход сотрудничество → самочувствие → исходный урок.
- Reload восстанавливает подтверждённый результат и последний постоянный урок; незавершённые ответы после reload по-прежнему не восстанавливаются. Не считать это синхронизацией между устройствами.
- Сравнение выгрузки с HEAD F-02: 20/20 записей полностью совпадают после исключения availability, entryTopicId и homeTopicId. Snapshot обновлён только для этих полей.

## Проверки

`permanent-preparation.test.tsx`: у всех 20 unit IDs ровно один основной дом; каждая тема достижима из каталога без карточки подготовки; десять школьных quiz записывают прежний prep:<unitId>, сохраняют старый результат R/RR и читаются после remount по реальному lastTopicId. Отдельно проверяются legacy-продолжение и возвраты из cooperation/wellbeing.

Существующие тесты подготовки теперь запускают совместимый старый вход явно, вместо клика по удалённой карточке. Тесты чтения по-прежнему проверяют общие результаты и лучший повтор через legacy-вход. Алгоритмы проверки и ограничения времени тестов не менялись; в больших фонетических тестах запросы кнопок ограничены карточкой конкретного слова.

Полный `npm run check` прошёл: lint, TypeScript, 120 domain tests, 307 component tests и 20 server tests, production build. Финальный профильный прогон: 78/78. Pages build прошёл; asset guard проверил 87 ссылок и 114 файлов. Браузерная проверка возврата также обнаружила прежний лишний параметр SVG-значка самочувствия — он исправлен без изменения логики занятий.

В браузере проверены все десять новых уроков через реальные тематические карточки, список десяти языковых тем, клавиатурный выбор букв, завершение timeline, reload и продолжение по его новому навигационному ключу. Старые результаты алфавита и timeline сохраняются. Для изолированного QA-профиля восстановлен старый lastTopicId=school:preparation; проверены оба возврата cooperation → feelings → исходный урок (legacy и постоянный), выбранный ответ и неизменность результатов. Экраны 390×844 и 1440×1000 не имеют горизонтального переполнения. Озвучка на слух и screen reader не проверялись.
