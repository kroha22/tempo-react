# F-08.2 — Еда и предпочтения

2026-11-14. Взрослый флоу по [карте F-07](FOOD-FLOW-F07.md), поверх [готового Card Save F-08.1](FOOD-CARDS-F08-1.md).

## Доступный результат

`#/learning/food?topic=fruit&phase=explanation`: общий план → «Еда и предпочтения · единый урок», либо Все темы → «Еда и предпочтения».

Три раздела: фрукты, продукты и напитки, предпочтения. В каждом доступны объяснение, слова, задания, повторение. Для фруктов и продуктов добавлены краткие PT/RU-вступления из существующих примеров; предпочтения используют прежнее объяснение GOSTAR DE и конструктор. Португальский показан по умолчанию, подчёркнутые слова открывают перевод и доступную в браузере озвучку. Полный русский режим включается отдельной кнопкой.

Подсказки продуктов сохраняют существующую карточку. Формы gosto de / gostas de / gosta de ведут к общей цели gostar de U49. Остальные слова объяснения дают перевод без создания неподтверждённого нового словаря. Пачки слов используют FoodCards; повторение фильтрует общую очередь SRS по 15 прежним целям.

## Состояние и совместимость

- Один EverydayLesson хранит конструктор и пять проверок; контролируемый режим меняет только показ объяснения/задания. Отдельный UsagePractice сохраняет исходные две фразы. Письмо использует прежние наборы 6/8.
- Переключения шагов, тем и возврат из объяснения -AR сохраняют незавершённые ответы в текущем флоу. После перезагрузки восстанавливаются URL, карточки, отзывы и подтверждённые результаты; черновики не обещаются.
- Четыре владельца результата остаются раздельными: `practice:words:expansion-food-fruit`, `practice:words:expansion-food-meals`, `practice:everyday:likes`, `usage:food-likes`. Нет общей оценки освоения еды. Старое completion без счёта показывается как пройденное без выдуманной оценки.
- Три прежних источника сохраняют ID и названия; обновлены только href к соответствующему шагу полного флоу. U49, книжные связи, отдельные gostar / gostava de и все остальные источники сохранены.
- `/learning/food/cards`, `/learning/everyday/likes` и три старых planStep доступны. Отдельные словарные материалы остались в раскрываемом блоке каталога.
- API, схемы localStorage/IndexedDB, JSON backup и алгоритм SRS не менялись. Новые цели и миграции не добавлены.

## Проверка

`npm run check`: 128 domain, 332 component, 20 server tests; production build. `npm run build:pages`: сборка и проверка 87 ссылок / 114 публичных файлов.

Пять новых component tests проверяют PT/RU, идемпотентный Save из подсказки и пачки, переиспользование U49, черновики, related return, независимые результаты 6/8/5/2 и legacy completion. Сравнение с точным F-08.1: content pack, learningCatalog и все review cards идентичны; IDs/метаданные источников идентичны, изменены только три href.

Браузерная проверка: взрослый профиль, 390×844 и 1440×1000; PT/RU, подсказка → Save, черновики обоих наборов письма, конструктор → проверка → -AR → возврат. В ходе проверки исправлена общая мобильная раскладка подсказки: сообщение озвучки больше не сжимает перевод и Card Save. Фактическое звучание системного голоса не подтверждено автоматизацией.

Скриншоты локальной проверки: `/private/tmp/tempo-f082-mobile-popup.png`, `/private/tmp/tempo-f082-desktop.png`. Публикация подтверждается отдельно точным SHA и terminal-статусами GitHub Actions в приватном текущем roadmap.
