# Взрослый словарь Gramática Ativa 1

Дата: 2026-11-01. Реализован локально, без публикации. Все 54 темы доступны как словарь; полноценные грамматические уроки пока только U18–U23.

## Результат нормализации

- 463 исходные строки сохранены со всеми полями: unit, preview/core, pt, ru, source_status, tags, unique_key.
- CSV с BOM и исходный JSON совпадают построчно; runtime snapshot проверяется на равенство оригиналу.
- 363 написания сведены к 362 значениям. Это редакционное число, а не подсчёт одинаковых русских переводов.
- 473 связи «строка → значение»: некоторые строки явно содержат несколько смыслов. Все исходные строки и все 54 урока покрыты; этапы preview/core остаются свойствами связи с уроком.
- 20 существующих StudyItem IDs переиспользуются по явному списку эквивалентности; добавлены 342 новых. Вместе с прежними 57 в manifest теперь 399 StudyItems. Старые definitions не переопределяются.

Показательные решения:

| Исходник | Решение |
|---|---|
| há / houve / havia / haverá в U30 | Одно значение существования и существующая `study:chunk:ha-presence`; формы и строки источника сохранены |
| há в U54 | Отдельные «… назад» и «уже … длится», не значение существования |
| para | Раздельные цель, направление и адресат; связь с конкретным уроком ограничивает значение |
| português | Человек и характеристика происхождения — разные части речи и значения |
| saber, ouvir | Знать факт / уметь и слышать / слушать разделены |
| muito; como; quando; quem; qual | Количество, степень и синтаксические роли разделены по контексту урока |
| queria → querer; podia/poderia → poder; preferia → preferir; deveria → dever | Общий инфинитив на карточке, исходная форма и контекст остаются в связях |
| gostava de / gostaria de | Одна карточка пожелания с прежним `study:chunk:ga1:gostava-de`; разные грамматические конструкции не становятся взаимозаменяемыми ответами урока |
| este/esta, meu/minha, tanto/tanta/tantos/tantas | Морфологические варианты одного значения объединены |
| o livro, enquanto | Прежние `study:noun:livro` и `study:chunk:ga1:enquanto`; новые уроки добавляют источники, а не новые пользовательские карточки |

Синонимы с разными леммами не склеиваются из-за одинакового перевода. Ранг, basic и расписание 1000 глаголов не меняются. Новые Sense-specific карточки глаголов не подменяют существующие `v0001–v1000`, чьи широкие значения и прогресс остаются у прежнего владельца.

## Данные и стабильность

`features/content/gramatica-vocabulary-source.json` — неизменённый snapshot входного JSON. Порядок его строк фиксирован; source row aliases служат прослеживаемости и не являются IDs карточек. Не переставлять строки ради сортировки интерфейса.

`gramatica-vocabulary-editorial.ts` — явные части речи, смысловые развилки, объединение форм, noun morphology, авторские pt-PT/ru examples и список переиспользования. `gramatica-vocabulary.ts` строит нормализованный реестр: entry/lexeme/sense/StudyItem ID, формы, примеры, все source row IDs и units. Перевод и позиция в уроке не входят в ID значения. Существующие StudyItems остаются владельцами своих canonical target IDs; intake-значение связано с ними через явный StudyItem mapping, без миграции прежних language entities.

`gramatica-vocabulary-pack.ts` добавляет новые StudyItems, chunks, examples и русский слой в общий manifest. Noun cards имеют артикль и plural; `os óculos` помечено plural-only. Other `word` cards хранят часть речи и Sense. Примеры — авторская тематическая адаптация, не OCR и не дословная выписка из PDF.

## Интерфейс и сохранение

Обучение → Gramática Ativa 1 → «Словарь и карточки всех 54 уроков». В U18–U23 есть ссылка на свой словарь; из раздела Карточки можно открыть весь набор. Словарь: `/learning/gramatica-ativa/vocabulary`, отдельный урок: `/learning/gramatica-ativa/vocabulary/u54`. В статическом демо те же пути используются после `#`.

Карточки поддерживают PT→RU и RU→PT, поиск, preview/core, перелистывание и раскрытие всех привязок к урокам. На португальской стороне показан контекст для различения одинаковых лемм. Просмотр и переворот не объявляют слово выученным.

Явное сохранение вызывает существующий StudyItem API. Ключ карточки остаётся прежним; контекст `unit:ga1:uNN` добавляется в существующую study_item_sources. Повтор из того же урока идемпотентен. Другой урок добавляет source, сохраняя savedAt и reviewItemId. DTO источников теперь возвращает необязательный непустой sourceContextId; старые ответы без контекста остаются совместимыми.

Библиотека сохранённых слов показывает перевод, пример и ссылки обратно к словарям уроков. На этапе нормализации сервер хранил Card Save и источники; следующим этапом добавлен [общий SRS через API/D1](SRS.md). Существующий прогресс глаголов сохраняется. В статическом демо словарь можно изучать, но серверное сохранение недоступно и явно обозначено. Детская копия не создавалась.

Сама нормализация не меняет схему D1. Последующий SRS имеет отдельную добавочную миграцию. Код не переписывает таблицы прежнего прогресса и не выполняет массовое автосохранение всех слов пользователю.
