# U01–U03 и быстрый разбор слов

Актуальное дополнение: [U01–U03 получили отдельные проверки; смешанное повторение U01–U11](U01-U03-MIXED.md). На GitHub Pages включены локальные сохранения и JSON-копии; сведения ниже о статическом просмотре без сохранения — исторический отчёт первого этапа.

Дата: 2026-11-02. Локальная реализация, без публикации.

В каталоге `/learning/gramatica-ativa` добавлены первые три темы: SER, ESTAR, SER/ESTAR. Кнопка «Объяснение и практика» ведёт на существующий `/learning/practice?lesson=ser`, `estar`, `ser-estar`. Новые Lesson ID, зачёты и копии упражнений не создаются. Это подключение готовых уроков, а не новые диагностические банки по полному объёму книжных разворотов.

«Разобрать слова» открывает `/learning/gramatica-ativa/words/u01` (аналогично u02, u03). Этот экран доступен также из словаря любой из 54 тем. Показана вся тематическая подборка выбранной темы, разбитая счётчиком на пачки до 8 значений.

- «Знаю» — перейти к следующему слову, без изменения расписания или записи освоения.
- «В карточки» — сразу сохранить через существующий API и перейти дальше только после подтверждения. Источник: прежний курс и `unit:ga1:uNN`. Существующая карточка сохраняет ID, расписание и прежние источники.
- Если источник этого урока уже сохранён, «Уже в карточках» просто продолжает просмотр. Если карточка была сохранена в другой теме, повторное сохранение добавляет источник текущей темы.
- Перевод/пример раскрываются по желанию. «Пока пропустить» не создаёт запись прогресса.
- Двойное нажатие не создаёт две операции. При ошибке слово остаётся; повтор отправляет исходный clientEventId. Итог показывает количество решений и переход к уроку/повторению.

Сохранённые карточки доступны в общем SRS/API/D1 после перезагрузки. Позиция разбора, «Знаю» и пропуски — только текущая сессия; после перезагрузки просмотр начинается заново, уже сохранённые карточки распознаются с сервера. Самооценка не заменяет durable progress. Для отдельного долгосрочного состояния знакомства потребуется следующий контракт, сейчас его не вводим.

В статической демоверсии можно просматривать перевод и пропускать слова, но сохранение отсутствует и явно подписано. Текущий словарь остаётся тематическим, не объявляется полной выпиской страниц PDF. Новых таблиц, миграций и изменений SRS нет.

## Проверки

Компонентные проверки покрывают ссылки на прежние уроки, ожидание server ack, двойное нажатие, сохранение исходного intent при повторе, завершение просмотра знакомых слов без сохранений и ограничения демоверсии.

На Node 22.23.2 прошли lint/TypeScript, 105 доменных тестов, 217 компонентных тестов (40 файлов, повтор с `--maxWorkers=2` после таймаута старого фонетического теста в общем параллельном прогоне), 20 серверных тестов, production build и build:pages. Новые тесты вместе с прежними словарными: 5/5.

В локальном браузере проверены 390×844 и 1280×900: сохранение с источником U01 через API/D1, распознавание после перезагрузки без дубля, пропуск знакомых, итог U03 и переход в прежний `ser-estar`. Скриншоты: `output/playwright/ga1-word-batch-mobile.png`, `ga1-word-batch-desktop-summary.png`. Схема не менялась, миграция не нужна. Публикации и push не было.

Также проверены Enter на «Знаю», отсутствие горизонтального переполнения на мобильном и статическая демоверсия: перевод/пропуск работают, кнопки сохранения нет. Общий docs-check сообщает отсутствие локальной папки `skills/` и старые битые ссылки в служебных документах; изменённые ссылки плана проверены отдельно, `git diff --check` чистый.
