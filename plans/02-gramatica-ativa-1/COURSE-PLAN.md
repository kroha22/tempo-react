## Как учитывать выполненные страницы

Это сведения из предоставленного плана, а не заново подтверждённые результаты ученика:

- U01–U17: в основном заполнены → предложить повторение первым действием.
- U18–U19: значительные незаполненные участки → предложить обучение, оставить проверку знаний доступной.
- U20–U23: частичные ответы → предложить диагностику.
- U24–U54: преимущественно новые темы → предложить обучение. В исходнике отдельно отмечены записи у U26–27, U32, U35, U39, U41–42, U51–53; для них предложить выбор проверки или полного урока. Исходное упоминание «страниц» неоднозначно: до визуальной сверки не присваивать этим номерам подтверждённые страницы PDF.

Для каждой темы отдельно храним/показываем: сведения о книжных упражнениях, наличие объяснения и практики в Tempo, пользовательский результат проверки. «Есть записи», «объяснение доступно», «урок завершён», «цель продемонстрирована» — разные факты. Ничего из книги автоматически не переносится в D1 как освоение. Старое прохождение Tempo тоже не превращаем в новый результат диагностики книги.

## Один сценарий для каждой темы

1. **Слова со страниц темы.** Список с переводом и примером; предварительно разобрать небольшую пачку 4–8 значений. Пользователь может пропустить этот этап. Максимум 14 новых значений за одно занятие, большая тема делится.
2. **Выбор действия:** «Повторить / проверить себя», «Разобрать тему», «Открыть объяснение». Для заполненных тем первым предлагается повторение. Объяснение доступно и до проверки, и после ошибки, и после завершения.
3. **Повторение:** 6 независимых заданий, в том числе 2 на воспроизведение. При 5/6 и двух правильных воспроизведениях — короткое резюме правила и выходная проверка. Иначе — объяснение именно слабого навыка и практика. Успех не скрывает объяснение.
4. **Обучение:** ситуация → русское объяснение с pt-PT примерами → упражнения с объяснением ошибок → применение в новой ситуации. Берём готовые компоненты и язык, дописываем только недостающее покрытие.
5. **Выход:** 5 отдельных заданий, не копии входных, минимум 4/5 и верный ключевой навык. Собственная свободная фраза — самопроверка по модели, без оценки строгим совпадением строки.
6. **Дальше:** итог по навыкам, возврат к нужному объяснению, следующая тема по книге, явное сохранение выбранных карточек. Повторение грамматики после перерыва отдельно от SRS слов.

Это целевой сценарий всех тем. Многофазный runtime сейчас реализован только для U18–U23. Старые уроки используют свои механики; их результаты и ID сохраняются. Для подключения в книжный маршрут нужны явные связи с существующими владельцами прогресса, без автоматического зачёта и дублирования записей.

## Слова именно со страниц учебника

Текущие 362 значения, 463 исходные строки и связи со всеми 54 темами сохраняем. Они помечены как тематическая адаптация, не исчерпывающая выписка. Запрос «слова со страниц» пока выполнен не полностью.

Для каждого разворота нужен проход: визуально прочитать объяснение и упражнения → выписать содержательные слова/выражения → проверить pt-PT/ru и морфологию → сопоставить с существующим значением → добавить точный источник. Существительные с артиклем и plural, глаголы по инфинитиву/значению, полезные выражения целиком. Инструкции и грамматические метки отделяем от активной лексики. Один и тот же смысл в разных уроках — одна сущность со всеми источниками. Разные смыслы одного написания не склеиваем.

Источник новой выписки должен содержать книгу, U, проверенную PDF-страницу, видимый печатный номер при наличии, раздел/упражнение и поверхность слова. Не менять ID существующего StudyItem при дополнении источника. Существующие строки адаптации не переименовывать в «дословно из книги» задним числом. До полной сверки интерфейс должен честно говорить «тематическая подборка», а не «все слова страницы».

Пример подтверждённого пробела: на просмотренной странице объяснения U01 есть `timorense`, `engenheiro`, `dicionário`, `madeira`, фразы о часах и географии. Их нужно проверять вместе со страницей упражнений; один перечень «профессии/национальности» полноту не доказывает. Этот пример не является завершённым импортом слов.

## Разобрать пачку слов перед уроком

Целевой экран: 4–8 значений из текущего урока, перевод по раскрытию, для каждого выбор:

| Действие | Значение для обучения | Что происходит с карточкой/SRS |
|---|---|---|
| Знаю | Не включать в новые слова текущего занятия | Не удаляет карточку, не ставит оценку, не переносит due |
| Не знаю / хочу разобрать | Показать перевод, пример и включить в подготовку | Само по себе не сохраняет карточку; предлагает явную кнопку |
| В карточки | Явно сохранить выбранное значение с источником урока | Существующий Card Save, один стабильный reviewItemId и общее расписание SRS |
| Пока пропустить | Вернуться позднее, без вывода о знании | Не меняет сохранения или прогресс |

«Знаю» — самооценка, а не доказательство освоения или высокая оценка SRS. «В карточках» и «знаю» — независимые признаки: пользователь может знать слово и всё равно сохранить его. Выбор не добавлять слово сейчас не означает удалить ранее сохранённое. Одно значение в нескольких уроках использует общее состояние знакомства; источник сохраняется у каждого книжного вхождения. После отметки «не знаю» можно разобрать слово и изменить самооценку.

После пачки показать сводку и дать подтвердить выбранное сохранение, продолжить к уроку или разобрать ещё. Ошибки/частичный успех сохранения отображаются по словам; повтор операции не создаёт дублей. Самооценку, если сохраняем между сессиями, проводим через аутентифицированный API/D1 отдельно от review events; не записываем фиктивные grades. Конкретный контракт и возможная миграция — следующий этап реализации после проверки текущей схемы.

**Сейчас работает:** фильтр по U01–U54, PT↔RU карточка, сохранение с источником урока, общее SRS/API/D1 и быстрый последовательный разбор «Знаю / В карточки / Пока пропустить». Решения и позиция разбора живут в текущей сессии, карточки сохраняются на сервере. **Ещё не работает:** устойчивое состояние знакомства со словом и полный постраничный словарь. В текущем быстром сценарии сохранение происходит сразу по каждому слову, без дополнительного общего подтверждения; ошибка оставляет слово для повтора. Старое SRS и ID не переделываем ради этой функции.

## Последовательность сборки

1. **Первые уроки U01–U11:** подключить готовые объяснения к книжной карте, добавить входные/выходные проверки и постоянный доступ к объяснению. Начать с U01–U03 как связанного блока SER/ESTAR. Параллельно сверить слова и выполненные упражнения на их разворотах.
2. **U12–U17:** дополнить частично готовое прошлое, формы и возвратность, создать недостающий COSTUMAR. Эти темы идут перед уже работающим U18, а не исчезают из курса.
3. **Единая подготовка слов:** реализовать пачку поверх существующего словаря/Card Save, отдельно от SRS. По мере постраничного прохода дополнять источники и лексику всех тем.
4. **U18–U23:** сохранить готовые ID/банки и прогресс, включить в полную карту; сделать объяснение доступным вне последовательного шага. Добавить смешанное повторение после U23.
5. **U24–U35:** новые объяснения и практика; использовать существующие опоры только для соответствующих целей.
6. **U36–U45**, затем **U46–U54:** расширить готовые семью, пространство, часы, GOSTAR DE до объёма соответствующих тем, создать отсутствующие объяснения и задания.
7. После блоков U11, U17, U23, U35, U45, U54 — смешанное повторение с результатом по навыкам. Это новые задания, не повтор тех же ответов. Связи слабая цель → объяснение → целевая практика. Педагогическое повторение грамматики не считать реализованным лишь потому, что есть словарный SRS.

Каждая тема готова, когда проверены страницы/источники, слова доступны списком, есть объяснение и два маршрута — повторение и обучение, независимый выходной контроль, сохранение/возобновление через существующий API/D1, обратный переход из объяснения и карточек, мобильная и клавиатурная проверка. В приложении нельзя выдавать планируемую тему за готовый урок. Публикация отдельно.

## Результат текущей проверки

- Все 54 темы разложены по стартовому сценарию, существующим опорам и недостающей работе.
- Уточнено, что повторение тоже включает доступное объяснение, а не только тест.
- Сформулировано различие тематического и постраничного словаря и сценарий разметки пачки слов.
- Исходная сверка меняла только документы. Следующий блок подключил U01–U03 по ссылкам и добавил быстрый разбор слов; подробности в FIRST-UNITS. Единый экран всех 54 уроков, новые диагностики U01–U17, долгосрочная разметка знания и постраничный импорт ещё не реализованы. Схема/API-контракты, ID и прежний прогресс не менялись; сохранение выбранных карточек использует существующий API.
