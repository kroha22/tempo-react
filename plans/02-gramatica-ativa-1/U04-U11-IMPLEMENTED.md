## Пользовательский путь

В `/learning/gramatica-ativa` теперь U01–U11, затем прежние U18–U23. У каждой из восьми новых тем: «Разобрать слова», «Объяснение и практика» по прежнему адресу и «Проверить себя» с новым самостоятельным банком. У U07 есть дополнительная ссылка TRAZER. Пачка слов тоже ведёт и в старый урок, и в новую проверку.

|---|---|---|---|

Всего 140 новых заданий, прежние 90 заданий U18–U23 не менялись. Из входных шести два требуют ввода; успешный вход 5/6 плюс оба воспроизведения → резюме правила и выход. Иначе → практика с объяснениями. На выходе нужно 4/5 и верное ключевое задание. Вопросы/контексты входа и выхода различаются. Это проверка заданных навыков, не доказательство освоения всех форм книги.

Правила и примеры берутся из существующих `shortGrammarLessons`, уточнения нового банка дополняют их, не переписывают старые уроки. Формы FAZER, DIZER, TRAZER и IR сверены с resolver; многих остальных глаголов в нём пока нет, для них формы явно заданы и сверены с таблицами книги. Таблицы самого тренажёра не расширялись. Принимаются обе европейские формы `ouço / oiço`. Диакритика значима: `veem / vêm`, `tem / têm`, `saímos`; контекст различает обычное действие и процесс, hoje/agora не объявляются автоматическими переключателями времени. У состояния/желания допускается обычное presente.

Новая практика использует прежний coordinator и API learning events/progress/complete. Старые Lesson ID и их результаты не переименовываются и не переносятся в новые банки автоматически. Номер U остаётся источником. Завершение и исторический лучший результат разделены; повторная попытка не стирает прежнее освоение. Пакет получает новый Unit для настоящего и уровень A1.2, прежние Unit/Level U18–U23 сохранены.
