# Детская подача: только необходимая адаптация

Основной документ: [взрослый план](README.md). Одна детская подача, без отдельных миров и отдельной программы. Текстовый вариант предполагает самостоятельное чтение; курс для 5–7 лет этим планом не заявляется.

| Блок | Решение |
|---|---|
| U01–U17 | Сначала использовать общее ядро. При необходимости заменять профессиональные/взрослые контексты знакомыми ситуациями; не упрощать языковые правила |
| U18 | Два параллельных домашних действия на картинке; возраст и часы остаются общей целью |
| U19 | Три кадра: фон, событие, последствие. Порядок кадров не заменяет понимание одновременности |
| U20 | Просьба о воде или помощи вместо взрослого обслуживания; сохранить целевую форму и регистр |
| U21 | «Уже закончил задание, когда пришёл друг» вместо вокзала, только если вокзал мешает пониманию |
| U22 | Повторяющиеся занятия и чтение вместо работы; не подменять временем «сейчас» |
| U23 | До/во время/после рисования или обеда. Те же три конструкции |
| U24–U54 | Решать после взрослого сценария и проверки понятности; не создавать заранее 31 копию урока |

Менять можно русскую длину подсказок, оформление, иллюстрацию и размер раунда. Общий пример и ответы предпочтительно оставлять теми же. Если меняется португальская фраза, это новый общий ExerciseItem с собственным ключом; детская подача лишь выбирает его из общего банка. Не переопределять ответ существующего задания и не выдавать подсказку за независимое доказательство навыка.

Короткие раунды по 5–8 минут с продолжением той же сессии. Прогресс принадлежит профилю ученика, а не визуальному режиму. Переключение подачи не открывает новый курс и не сбрасывает результат.

У каждого перетаскивания есть вариант кнопками или списком; картинка сопровождается текстовым описанием. Значение и правильность не передаются только цветом. Цвета групп сохраняются: -AR красный, -ER зелёный, -IR синий, неправильные — фиолетовый/золотой.
