# Профили и продолжение занятий

23 октября 2026. Доработка существующего локального Demo, не новая система аккаунтов.

Уже существовали: взрослые/детские профили, отдельные namespace для плана и карточек, перенос старых данных копированием, граница QueryClient при смене профиля. Стабильные ID карточек и прежние ключи сохранены.

Добавлено: карточки выбора с именем, подачей, количеством пройденных занятий из 23, наградами темы состояний из трёх и кнопкой «Продолжить». «Начальный этап» не является оценкой CEFR. В данные профиля версии 1 добавлено необязательное поле learning: старая запись читается с пустым состоянием без перезаписи. Все сохранения плана/карточек сохраняют learning и наоборот.

Для «Как я себя чувствую» сохраняются открытые переводы, два результата практики и выбранный раздел. При выборе профиля открывается последняя тема; для состояний восстанавливается раздел. Незавершённый проход заданий начинается заново. Возврат к плану делает его текущим направлением продолжения. Другие темы продолжаются с начала темы. Все три пилотных урока берут подачу из профиля, а связанный тренажёр тоже использует профиль вместо параметра URL. Вне профилей переключатели остаются для самостоятельных preview и тестов.

ProfileLearningContext отделяет UI от локального адаптера github-pages/profiles.ts. Запись происходит до подтверждения награды; сбой сохраняет последнюю попытку в памяти и показывает повтор сохранения. При смене профиля локальные состояния и query cache пересоздаются. Повреждённые данные не стираются; проблемный профиль не открывается, остальные остаются доступными.

Хранение относится только к браузерному демо на этом устройстве. D1/API основного приложения не заменены локальным хранилищем и не изменены. Для серверных профилей нужны отдельные владельцы и связи с аутентифицированным пользователем, миграция D1 и API проверки принадлежности; текущие локальные ID не являются аутентификацией. Публикация этим этапом не выполняется.

QA: полный компонентный прогон 129/129 в 24 файлах; отдельно после уточнения подачи общего SER — 10/10 (profile-manager/first-steps). TypeScript, lint, 92 domain-теста и 16 HTTP/server-тестов прошли. Production Worker build и статический build:pages прошли. Документная проверка: прежние девять предупреждений о структуре заголовков. Браузер на 390×844 и 1280×950: взрослый и детский профили, получение награды, перезагрузка и возврат в раздел примеров, отдельное завершение SER взрослым, прямое продолжение на ESTAR, независимые счётчики и выбор профиля. Изоляция cache сохраняется существующей SessionQueryBoundary; сохранение карточек при записи learning дополнительно проверено тестом. В браузере не тестировалась реальная SRS-сессия карточек и синхронизация между вкладками. Скриншоты: output/topic-research/profiles-mobile.jpg и profiles-desktop.jpg.
